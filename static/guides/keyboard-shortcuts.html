Coverage and limitations

    Terminal

    On the Mac, keys prints the reference in new or reloaded shells; an existing shell can run source ~/.zshrc. It is a command, not a chord. Direct invocation: python3 ~/dev/visual-guides/keyboard_reference.py (Python 3.9+, no dependencies). Add a search phrase or --all to include disabled mappings.

    Default output shows grouped keys, actions and statuses. Use --details for each row’s conditions, limitations, sources and verification date; --notes prints catalog-wide caveats after the results. --json always includes complete records and notes.

    Keeping this current

    When a custom BTT, iTerm, zsh or harness mapping changes, update the canonical catalog in the same task and verify this guide and the terminal output. A verified date records a source check, not a claim that the shortcut was exercised in every app. Review every catalog string before publishing; automated privacy checks catch common leaks, not every private detail.

    Keycaps separated by an arrow are consecutive sequence steps, not one simultaneous chord. Search can join those steps, such as cosnt for C → O → S → N → T → Space. Built-in macOS shortcuts are outside this custom reference.
